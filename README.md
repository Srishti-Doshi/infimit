# INFIMIT: Redefining Higher Education Intelligence

Welcome to the official repository for the **INFIMIT Website Redesign & AI Integration Project**.  
We are transforming **infimit.in** into a next-generation, AI-enabled news and events platform designed for the global higher education ecosystem.

---

## Project Vision

Our goal is to bridge the gap between premier educational institutions and the global student community.

By leveraging the **MERN Stack**, we are building a scalable platform that delivers real-time news from **IITs, IIMs, and Central Universities**, enhanced with the power of Artificial Intelligence.

---

## Key Innovations

- **AI-Powered Summarization**  
  Instantly distill complex educational news into concise highlights.

- **Smart Event Generation**  
  Automatically generate event titles and descriptions using advanced LLMs.

- **Institutional Ecosystem**  
  Role-based dashboards for institutions to manage and publish content.

- **Intelligent Recommendations**  
  Personalized content suggestions for users based on interests.

---

## echnology Stack

- **Frontend:** React.js
- **Backend:** Node.js & Express.js  
- **Database:** MongoDB  
- **AI Engine:** OpenAI API
